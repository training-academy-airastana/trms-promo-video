# Озвучка TRMS

Настройки 60-секундного монтажа: `voiceover/trms.json`. Подготовлены девять английских реплик George и оригинальная инструментальная музыка ElevenLabs. Цифры демонстрационные; они не произносятся как подтверждённые достижения, на экране сохранено `Illustrative data`.

Ключ загружается из `.env.local` через Node, официальный SDK читает `ELEVENLABS_API_KEY`. Не переносить ключ в исходники или клиентский код.

Команды из корня проекта:

- `npm run voice:plan` — показать актуальный сценарий без API-запросов.
- `npm run voice:list` — получить доступные голоса и существующие превью, без синтеза речи.
- `npm run audio:generate -- all --confirm` — создать отсутствующие голосовые реплики и один музыкальный трек; существующие файлы повторно не генерируются.
- `npm run audio:generate -- voice --confirm` — только недостающие реплики.
- `npm run audio:generate -- music --confirm` — только музыкальный трек, если его ещё нет.
- `npm run audio:mix` — пересобрать сведение локально без API-запросов и кредитов; используются Python, NumPy и FFmpeg из установленного Remotion.

Генерация расходует кредиты ElevenLabs. Выбран George, без утверждения о сходстве с диктором SCALE. TTS — `eleven_v4`, музыка — `music_v2`. Перед синтезом проверяются доступная TTS-модель и остаток включённых кредитов; автоповторы и автоматическая покупка кредитов не включаются. Снимок счётчика использования не является окончательной суммой списания.

Текущая версия — `public/audio/trms/2026-10-25-v1/`: исходные MP3, `plan.json`, точные голосовые интервалы в `manifest.json`, три WAV-дорожки и `master.wav`. Биллинг-метаданные находятся в `output/audio-generation-metadata.json`, вне публичных ресурсов.

Речь не ускоряется и не растягивается: удаляется только концевая тишина с запасом для дыхания. Музыка плавно приглушается на 8 дБ во время реплик. Два тихих воздушных акцента совпадают со вспышкой и пространственным переходом. Общая обработка пиков применяется к трём дорожкам согласованно, поэтому их сумма в Studio совпадает с мастер-файлом. WAV: 48 кГц, стерео, 24 бит; мастер — около −16.24 LUFS и −1.36 dBTP.

`src/film/FilmAudio.tsx` подключает голос, музыку и воздушные акценты на отдельных Track. Подключённые сцены обрезают те же дорожки по своим абсолютным временным смещениям.

Экспорт со звуком: `output/trms-full-film-hq-with-audio-v3.mp4`. Видеопоток скопирован из готового HQ-экспорта без повторного сжатия; звук — AAC со стерео и частотой 48 кГц.

`direction` — редакторское описание подачи, не системная инструкция API. Паузы задаются пунктуацией и размещением реплик. Музыка задаётся отдельным полем `music`; атмосферные акценты воспроизводимо синтезируются локально.
